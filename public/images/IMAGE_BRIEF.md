# 이미지 소스 브리프: "에어컨은 어떻게 차가워질까?" 쇼츠

Codex의 이미지 생성 기능으로 아래 이미지 7장을 만들어 이 폴더(`aircon-shorts/public/images/`)에 정확한 파일명으로 저장해 주세요.
이미지는 Remotion 영상(세로 1080x1920, 짙은 네이비 배경 #0B1530)에서 움직이는 소스로 쓰입니다.

## 공통 스타일 (모든 이미지 동일하게 유지)
- 깔끔한 3D 클레이/소프트 렌더 아이콘 일러스트. 둥근 형태, 부드러운 조명, 약간의 광택
- 색: 시원한 아이스 블루(#5BC8FF), 화이트, 차가운 회색 + 열을 뜻하는 따뜻한 오렌지(#FF7A3D) 포인트
- **투명 배경 PNG**, 피사체는 중앙에 두고 가장자리에 여백 약 10%
- 이미지 안에 글자, 숫자, 로고, 워터마크, 실존 브랜드는 절대 넣지 않기
- 1024x1024 (정사각형)
- 투명 배경을 만들 수 없으면 완전 단색 #FF00FF(마젠타) 배경으로 만들고 보고에 그렇게 적기

## 이미지 목록
1. `indoor_unit.png`: 벽걸이 에어컨 실내기, 3/4 정면 각도. 아래쪽 바람구멍에서 연한 파란 냉기 곡선이 살짝 흘러나옴
2. `outdoor_unit.png`: 에어컨 실외기, 3/4 각도. 앞면에 큰 원형 팬 그릴, 옆에 구리 배관 2개
3. `compressor.png`: 냉매 압축기. 짙은 회색 원통형 몸체, 위쪽에 구리 파이프 연결부. 기계 부품 단독
4. `hand_sanitizer.png`: 손바닥 위에 투명한 젤 방울. 방울 위로 증발하는 작은 김과 파란 냉기 표시 (손소독제를 바르면 시원한 느낌)
5. `sun_hot.png`: 뜨거운 여름 해. 오렌지/노랑, 아지랑이 느낌, 얼굴 없이
6. `person_hot.png`: 더워서 녹을 듯한 사람(성별 모호한 둥근 오리지널 캐릭터, 상반신). 땀방울, 부채질
7. `person_cool.png`: 6번과 **같은 캐릭터**가 시원한 바람을 맞으며 행복하게 미소 짓는 모습(상반신), 주변에 파란 눈송이/바람 곡선
